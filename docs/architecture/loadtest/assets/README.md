These downloaded SVGs are stored locally so the architecture diagram renders
offline and does not hot-link third-party assets.

| --- | --- | --- |

| `microsoft-sql-server.svg` | Devicon, `icons/microsoftsqlserver/microsoftsqlserver-original.svg` | MIT |
| `apache-hive.svg` | Simple Icons, `icons/apachehive.svg`; local fill set to the Hive yellow | CC0-1.0 |
